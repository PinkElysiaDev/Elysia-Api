# 登录角色描边：实际审查记录

## 审查范围

源视频为仓库现有 1920 × 1080、60fps、16 秒素材，目标为现有 `role-mask.png`。未上传素材到外部视觉服务，也未使用额外视觉模型账号或密钥。

本次审查包含每秒关键帧、眨眼附近的 3.8／4.0／4.2 秒、片尾 15.3／15.5／15.983333 秒，以及浏览器中明暗主题、桌面与移动端的实际过场截图。完整 960 帧的 PTS、分组、坐标范围、二进制长度、哈希及跨帧标识匹配由脚本检查；完整叠加视频和 60 张连续帧联系表保留在审图目录。

## 提取—审图—修正

| 轮次 | 观察与动作 |
| --- | --- |
| 基准 | 确定头发／发饰、面部、手部、服饰四组；排除浮空晶体、背景环带和光线。源、目标姿态不同，不按单一轮廓索引硬变形。 |
| 明亮轮廓 | 4 秒闭眼帧检查发现，单靠暗线提取会漏掉白色手套轮廓；补充当前帧边界边缘，保留闭眼时真正可见的线条。 |
| 发梢与下身 | 扩展细发梢范围，让细小附属区域跟随主头发追踪；收紧下身区域，过滤短的非面部碎线。 |
| 片尾局部 | 959 帧在原图 `(630,520)–(750,680)` 区域放大对比，确认肩部左侧的短蓝线是背景光环，不属于人物；记录局部排除区。 |
| 邻帧复核 | 918／930／959 帧对比发现，同类误抓随背景移动。沿实际肩部和上方披帛边界收紧整个服饰约束，避免只对单帧遮盖；对 930 帧新暴露的短发组边界候选补充局部排除。 |

校正坐标与说明保存在 `annotations.json`。每次改动都重新导出全部帧，并由构建校验保证标注、轨迹、素材和浏览器缓存版本一致。

跨帧审计还发现，单纯使用质心距离可能将邻近线段错误地复用为同一标识。现改为等距采样、局部光流、多点双向形状残差和一对一分配；线条分裂、合并、遮挡或匹配不确定时创建新标识，不强行续接。

## 浏览器同步复核

- 数值测试将投影函数与浏览器原生 CSS 几何位置对照，覆盖透视、呼吸缩放、漂移、桌面／窄屏／移动裁切。
- 在帧回调内阻塞主线程，实际复现了旧 `mediaTime` 与新解码视频帧不一致的情况。渲染器现在锁定不可变 `VideoFrame`，使用同一帧的时间戳和图像；不支持此能力时拒绝迟到回调。
- 粒子按部位落到目标笔画，出生位置不随之后的人物运动改变；描边分段脱离与粒子出生共用分组时间表。
- 桌面／移动端实景覆盖不同视频起点及循环接缝，检查中央文案、末帧零粒子、4 秒终点及目标图案原位交接。
- 暂停、系统减动效、省流、自动播放拒绝、无效资源、后台切换和 GPU 故障均有静态降级验证。

## 验收边界

`report.json` 中的骨架误差仅表示导出折线对提取骨架的几何偏差。`tracking-report.json` 的残差只用于判断跨帧身份匹配。**二者都不是人工独立语义真值，不构成“全片 960 帧全部线条误差 ≤2px”的认证。**

本次未对 960 帧逐像素建立独立人工真值；清晰主要线条的 2px 目标仍需要结合原分辨率审图器做最终质量验收。微弱线条、半透明发梢、细小饰物和遮挡交界应优先复查，不能用更粗的描边掩盖偏差。

性能报告使用本机无头浏览器的实际画布提交间隔，截图另行运行，避免图片编码阻塞污染测量。报告不替代物理移动设备的 GPU 帧率与功耗验收。复现命令和全部输出位置见 `README.md`。
