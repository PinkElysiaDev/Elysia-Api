## 已修复的行为

- **启动证据刷新**：缺当前编译器报告显示待刷新/刷新完成；损坏定义、存储及验证失败继续报错。保留现有验证、事务复核、发布顺序和用户配置。
- **Responses 辅助帧**：无 `headers` 的 `response.metadata` 与 turn-state 精确分派。对象载荷保持不透明；检查响应身份、序号及生命周期。同协议满足原生重放条件时保留帧字节；跨协议兼容模式省略并告警，严格/禁用模式拒绝。复用 `event-metadata`，不清除混入的正文、工具、usage 或错误。
- **最终交付**：Write、Flush、Finalize 失败进入一次最终调用记录。保留上游/协议/资源主因；区分确认断连、shutdown、deadline、未知取消和未知下游写失败。明确 RESET 的归因不再随探测先后变动；普通 abort/本地关闭不冒充客户端主动停止。
- **展示与截断**：调用记录增加可选 `delivery`，页面/导出分列上游 HTTP、调用结果和下游交付；尾 50 帧发生淘汰时正确标记截断。HTTP 200 不能证明客户端完整消费；历史记录没有被改写。

## 性能与内存代价

Windows/Ryzen 5 7600X、Go 1.27.2，`GOMAXPROCS=4`、`GOGC=100`、PGO关闭；普通负载 `GOMEMLIMIT=2GiB`，大图 `8GiB`。独立客户端、网关和模拟供应商，五对交替；正式计时无 profiler/主动GC，堆峰值为20ms采样。

| 场景 | 分配 MiB/请求，旧→新 | 完整消费中位延迟 ms，旧→新 |
|---|---:|---:|
| 短 Chat | 0.13 → 0.13（+0.64%） | 0.52 → 0.52 |
| Responses→Chat，1024帧 | 62.26 → 62.42（+0.26%） | 81.08 → 79.68 |
| 31MiB，正文日志关闭 | 259.70 → 259.50（-0.08%） | 716.44 → 697.17 |
| 31MiB，保存正文 | 867.22 → 866.92（-0.03%） | 751.47 → 801.65 |
| 31MiB，媒体外置 | 406.88 → 407.03（+0.03%） | 699.03 → 720.91 |

五组正常路径中，延迟和分配没有出现超过10%的中位回退。无正文日志的大图采样堆峰值首轮上升17.8%，独立五对确认则294.67→294.63MiB，未稳定复现；两轮结果都保留。流式与媒体场景的采样堆差异也见完整报告，不能由分配持平推导峰值必然不变。

**慢 Finalize 有实测内存代价**：在单份31MiB请求日志夹具中，保存正文约额外持有31MiB，媒体外置约23MiB，直到最终发送结束。这是整理后的日志资产，原捕获缓冲已释放；它不属于128MiB异步队列预算。发送/写入完成并主动GC后保留量回到基线附近。该所有权实验含客户端与合成输入，不能当作独立网关峰值；完整生产记录还可能保存出站请求等其他正文，该数字不是生产增量上限。

2MiB四并发取消的五对实验中，每版100次请求均正常退出，无重复上游调用；活动请求和队列归零，GC后网关堆约3.35MiB。31MiB媒体外置持续20轮，空闲堆反复回落，未观察到逐轮持续增长；有限实验不证明长期无泄漏。
