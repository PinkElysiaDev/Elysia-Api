## 批次 3：上游计数路由

dev.136 的公共别名和通用 gateway 按 count_tokens 声明分派，复用权限、候选、准备资源、
HTTP 传输及取消机制。逐候选编码，只有观察到可重试 HTTP 状态才切换候选；成功 HTTP 的非法
计数不重试。计数只占请求并发/次数，不估算生成输入、不发送生成调用、不写生成用量记录。

仅声明计数的包已通过协议编译/绑定合同测试；管理侧独立计数包绑定流程尚未作为支持入口验收。
