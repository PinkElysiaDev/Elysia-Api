## 批次 3：上游计数路由

dev.136 的公共别名和通用 gateway 按 count_tokens 声明分派，复用权限、候选、准备资源、
HTTP 传输及取消机制。逐候选编码，只有观察到可重试 HTTP 状态才切换候选；成功 HTTP 的非法
计数不重试。计数只占请求并发/次数，不估算生成输入、不发送生成调用、不写生成用量记录。
最终 wire 重新约束模型和实际输入能力，显式空 Key 权限仍表示无权限。

计数请求与生成共享包身份但具有独立执行指纹，避免转换缓存混用。修复计数加入操作列表后
误禁用生成能力验证 profile 的回归，以及 Gemini 同协议改写模型后重复保留请求形态的问题。
仅声明计数的包已通过协议编译/绑定合同测试；管理侧独立计数包绑定流程尚未作为支持入口验收。

Go 全量通过（protocol 4.639、builtin 30.357、server 127.703 秒），vet 通过。
确定性本地 HTTP 覆盖 Anthropic/Gemini 四种组合、文本/工具/图片、精确大整数、非法响应、
无计数候选、源 Key/模型组权限、重定向拒绝和上游取消。另补重试期间配置更新的快照测试。
定向 race 通过（取消、重试快照及转换缓存，105.888 秒）；先前包含全部计数用例的 race 在
240 秒处编译最后一个预置夹具时超时，未报告数据竞争，不计为通过。
本批精读计数实现、公共/gateway 调用、路由/准备/最终 wire 及转换缓存相关文件；生产默认
仍未切换，正式性能、浏览器和跨平台验收尚未完成。
