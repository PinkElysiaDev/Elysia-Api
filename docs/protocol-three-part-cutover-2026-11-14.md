## 唯一运行模型

- 大自在天 core2 是转换中心；每个 Mapping 仅连接自己的外部协议与核心。
- package=4、DSL=2、core=2；转换策略 schemaVersion=2 是独立版本，不属于旧协议定义。
- 默认包、启动恢复、编辑器、Agent、预览、验证与真实调用使用同一编译器和不可变修订。
- 不在线双跑，不失败换旧引擎；不注册旧 Module，也不在 DSL 中增加供应商分派。
- 用独立新库配置和验收，不迁移旧配置、绑定、任务或续传状态；现有数据库、日志和密钥不修改。

## 公开编写合同

编辑器只提供 Spec/Mapping 双源和完整 v4 包编辑。`spec` 中保存协议身份、外部文档、操作及生命周期；`mapping` 中保存双向核心映射及其能力、默认规则、样例。两份源共同保存、验证和激活，原始 JSON 的长整数和显式空值保持。

schema catalog 提供 package、spec、mapping、semantic、binding 和 conversion；不再发布旧 definitionSchema 或 modules。旧协议格式明确拒绝，不能通过改变编辑器模式恢复执行。
