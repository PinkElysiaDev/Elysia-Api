# 请求历史保留的声明式原型

本批接通 `reasoning.historyRetention` 的有限值映射与目标取舍。四个原型位于 `backend/protocol/testdata/history/`，只验证文本请求的历史控制切片；不是正式预置，不覆盖完整供应商协议。请求使用受限文本形态，响应样例是合成的独立文本合同。

四个现有预置与 `normalizeAnthropicThinkingRetention` 旧补丁仍在。生产加载入口未切换，不能将本批记为四预置迁移完成。

## 声明与执行

源原型使用 `aggregate.valueMapping` 声明固定核心值 `all`、两个完整 wire 对象及未知值的核心保存位置。两个对象的差别仅是 `keep:"all"` 与 `keep:{"type":"all"}`；具体字段及厂商名称只存在 JSON 原型中。

编译器证明以下关系后才允许执行：

- 解码程序对完整 wire 值进行等值比较；已知分支产生声明的核心值，其他值在 `unmatched` 参数路径原样保留。
- 编码程序使用声明的 wire 变体表达已验证的核心值；没有该核心意图时，使用保留的未知原值。
- 额外字段、其他编辑、有限保留数量及 null 不会因为部分字段相似而被识别为 keep-all。

证明发生在编译期，不在请求中额外执行一次转换或全文对照。缺失字段继续与 null 区分。没有 Native 时，已识别输入使用声明的规范 wire 变体；符合原生协调条件时，两种原始写法及原始字节仍可保留。

目标取舍继续使用同一个 `request-projection`、顺序 130：

| 原型目标 | 声明行为 |
| --- | --- |
| Anthropic | 有限值重建，保留未知控制及原生表示 |
| Gemini | `request_field` 的 default 明确为 all，省略该核心控制并记录无损规范化 |
| Chat／Responses | 明确 reject，不宣称其缺省行为等价 |

default 仅允许 `/reasoning/historyRetention` 的 `all`，只清除该字段；其他生成控制保持不变。兼容与严格模式均可执行这个限定的 default。禁用或同 ID 替换有效；编码器只拒绝未处置意图，不补执行默认规则。核心投影配置包含目标、映射哈希和实际引用的表达式，并在策略编译时缓存。

同 wire 的 Native 恢复不能仅凭当前字段已经为空得到授权。编码器沿用私有基线证据：原基线包含被处置的 history 意图时仍拒绝；基线不含该意图且身份、配置等匹配时允许正常重放。不伪造来源，不清空整份 Native。

## 验证范围

`builtin/history_declaration_test.go` 将 11 种已知／未知控制形态分别送入原实现和 JSON 原型，覆盖四目标、兼容／严格两种策略，共 88 个格子。比较接受／拒绝结果及成功输出的完整 JSON。源原型另验证同协议原始字节、声明证明失败、禁用／替换、其他生成控制不丢失及 Native 基线边界。

新声明的诊断使用核心字段路径与具名策略；上述矩阵不证明它与旧 native 扩展错误的路径、阶段逐字相同。真实供应商、完整客户端、所有消息类型、流式与性能验收仍未由这组原型覆盖。
